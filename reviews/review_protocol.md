# Review Protocol

## Daily Micro-Review

Before new cards, say yesterday’s 3 strongest cards.

## Weekly Review

1. Record 60 seconds.
2. Count pauses longer than 2 seconds.
3. Note 3 repeated errors.
4. Pick only one error for next week.
5. Save one sentence you liked.

## Monthly Review

Compare Week 1 and Week 4 recordings:

- Did sentence starts become faster?
- Did pauses reduce?
- Did grammar errors repeat less?
- Is pronunciation clearer on target sounds?
- Can you speak longer without panic?
