# Common Correction Cards

Learn the transfer pattern, not only the sentence. Each card takes under 60 seconds: correct it aloud, create one related sentence, then move on.

## C001. discuss about → discuss

**Incorrect version:** discuss about
**Correct version:** discuss
**Explanation:** Discuss is directly followed by the topic.
**Underlying rule:** Learn the verb pattern, preposition pattern, countability pattern, or tense trigger behind the correction.
**3 related examples:** Natural form: “discuss.” / Work context: “Please use: discuss.” / Self-correction: “Not the old phrase — discuss.”
**Transfer pattern:** Malayalam/Indian-English transfer often adds extra prepositions, uses continuous forms for state verbs, or translates local office phrases literally.
**ROI Score:** 10/10
**Reason it survived:** This error is common, noticeable, and easy to fix once the pattern is retrieved quickly.
**Quick drill:** Say the wrong form once, the correct form three times, then make one new sentence.
