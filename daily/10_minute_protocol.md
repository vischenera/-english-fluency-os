# Daily 10-Minute Protocol

Use a timer. Stop at 10 minutes even if you feel motivated.

## Minute-by-Minute

| Minute | Action | Output |
|---:|---|---|
| 1 | Warm start | Say yesterday’s 3 best expressions. |
| 2–4 | Framework retrieval | Use 3 framework cards in new sentences. |
| 5–6 | Correction pattern | Fix 1 correction card aloud. |
| 7–8 | Expression activation | Use 2 expressions in answer prompts. |
| 9 | Pronunciation | Do one minimal drill. |
| 10 | Score | Mark retrieval, hesitation, confidence. |

## Daily Rule

If you cannot start a sentence within 3 seconds, repeat the same card tomorrow. Do not add more cards.

## ADHD Friction Reducers

- Keep today’s cards open before starting.
- Use a visible timer.
- Speak standing up if attention drops.
- Record only on review days, not every day.
- End with one visible score.
