# Daily 10-Minute Protocol

Use a timer. Stop at 10 minutes even if you feel motivated. Consistency beats intensity.

## Minute-by-Minute

| Minute | Action | Output |
|---:|---|---|
| 1 | Warm start | Retrieve yesterday's Box 1 cards aloud (see review protocol). |
| 2–4 | Framework retrieval | Use 3 framework cards in new, real sentences. |
| 5–6 | Chunk + correction | Use 2 chunks aloud; fix 1 correction pattern. |
| 7–8 | Prompt activation | Answer 1 prompt from the prompt bank using today's cards. |
| 9 | Accent OR island | Run one mode from the accent menu, or retell one conversation island. |
| 10 | Score | Mark retrieval, hesitation, confidence (and on review days, longest fluent run). |

Rotate minute 9: pick one accent menu mode (see `curriculum/accent/micro_imitation_protocol.md`) most days; retell an island ~twice a week. Pick by mood — never force long audio.

## Daily Rules

- If you cannot start a sentence within 3 seconds, the card drops to Box 1 and you repeat it tomorrow. Do **not** add more cards.
- Keep Box 1 small (~5–8 cards). Don't add new cards while it's full.
- Speak everything aloud. Silent reading does not build retrieval.

## ADHD Friction Reducers

- Open today's cards and the prompt bank *before* starting the timer.
- Use a visible countdown timer.
- Speak standing up or walking if attention drops.
- Record only on review days, not every day.
- Always end with one visible score, even a rough one.
